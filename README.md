# Uni-Projects

A collection of data elaboration and simulation code developed during a **BSc in Physics at the University of Padua (UNIPD)**.

The repository gathers the code produced for academic lab work and thesis research, with a focus on data analysis and numerical/physical simulation.

## Contents

### `ARCADIA_thesis`
Code and material related to the bachelor's thesis work carried out within **ARCADIA** (Advanced Readout CMOS Architectures with Depleted Integrated sensor Arrays), an INFN collaboration developing next-generation fully-depleted CMOS Monolithic Active Pixel Sensors (FD-MAPS) for low-power, large-area particle tracking. This folder contains the analysis and/or simulation code produced in that context — for example sensor characterization, data processing from lab measurements, or simulation studies supporting the thesis.

### `LNGS - GSSI`
Code and material from research activity carried out at the **Laboratori Nazionali del Gran Sasso (LNGS)**, INFN's underground laboratory for astroparticle physics, and/or the **Gran Sasso Science Institute (GSSI)**. This folder contains data elaboration and/or simulation code developed for the sensor's characterization of the NUSES space mission.

## Purpose

This repository mainly serves as a personal archive of academic work completed during the degree, useful for:

- keeping data-analysis and simulation code organized in one place;
- documenting the work done for the bachelor's thesis and related lab activities;
- making the code available for future reference or reuse.

## Getting started

```bash
git clone https://github.com/Marco-42/Uni-Projects.git
cd Uni-Projects
```

Each folder is self-contained and relates to a specific project or activity — check the files inside for usage instructions.
